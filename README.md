# GLOBALSTEPPER E-Commerce Website

## Project Overview

GLOBALSTEPPER is a responsive front-end e-commerce website created for the CPU4104 Web Development assignment.

The website represents a unisex streetwear brand and allows users to browse products, view product details, search and filter products, add items to a shopping cart, update quantities and submit a validated contact form.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM manipulation
- Local Storage

No frameworks, external libraries or backend technologies were used.

## Website Pages

- `index.html` – Home page
- `products.html` – Product listing page
- `product-details.html` – Dynamic product details page
- `cart.html` – Shopping cart page
- `about.html` – About the brand
- `contact.html` – Contact form with validation
- `wishlist.html` – Saved products wishlist page

## Main Features

- Responsive mobile-first design
- Mobile navigation menu
- Twelve product listings
- Product search with live suggestions
- Category filtering
- Product sorting
- Dynamic product details
- Product Quick View modal
- Wishlist functionality
- Wishlist Local Storage persistence
- Add to Cart functionality
- Shopping cart drawer
- Cart quantity controls
- Remove products from cart
- Automatic cart total calculation
- Cart Local Storage persistence
- Dark and light theme toggle
- Saved theme preference using Local Storage
- Newsletter form validation
- Contact form validation
- Page loading animation
- Scroll reveal animations
- Interactive hover and shine effects
- Accessibility features
- SEO meta descriptions
- Open Graph metadata
